# openwebui

Open WebUI — self-hosted chat interface for LLMs. Connects to the LiteLLM
proxy as its backend.

## Install

From the `clusters/pax/` directory:

```sh
./deploy.sh openwebui install
```

## Upgrade

```sh
./deploy.sh openwebui upgrade
```

## Uninstall

```sh
./deploy.sh openwebui uninstall
```

## Access

- Private: `https://chat.guneet.xyz`
